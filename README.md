# Omnismo — Livro "Equinócio Omni"

Repositório contendo o material do livro "Equinócio Omni": fontes, capítulos e recursos relacionados ao projeto editorial.

## Sobre
Este repositório armazena o conteúdo do livro "Equinócio Omni". Pode incluir manuscritos em Markdown, imagens, arquivos fonte para geração de e-book/impresso e notas de produção.

## Estrutura
- /chapters/ — capítulos em Markdown
- /assets/ — imagens e recursos estáticos
- /build/ — artefatos gerados (PDF, ePub, etc.)
- README.md — este arquivo

(Ajuste a estrutura conforme o conteúdo real do repositório.)

## Como visualizar / editar
- Para editar capítulos: abra os arquivos em /chapters/ no seu editor de texto favorito.
- Para pré-visualizar Markdown localmente: use um visualizador de Markdown (VS Code, Typora) ou:
  - Instale uma ferramenta de visualização, por exemplo:
    - Visual Studio Code + extensão Markdown Preview
    - Ou rode um gerador de site estático (ex.: mdBook, Hugo) se desejar um site a partir dos arquivos.
